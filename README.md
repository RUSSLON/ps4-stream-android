# PS4 Stream Mobile — Android MVP v0.1

Android-приложение на **Kotlin + WebView** для отправки видео на PS4 через уже существующий сервер **https://ps4-stream.onrender.com/**. Никаких изменений серверного `app.py` для приложения не требуется: использует совместимый `POST /api/launch` со случайным **4-значным PIN** (версии сервера v0.3 / v0.4).

> **Статус:** исходный код MVP. JS-парсер прошёл автономные тесты. Сборку Android и работу на реальном телефоне / HDrezka проверить здесь не удалось — Android SDK недоступен. Проект можно собрать на GitHub Actions или в Android Studio. Видеоссылки должны быть доступны самому CDN / серверу Render; приложение **не устраняет** установленный ранее `HTTP 404` от CDN в другой сети.

## Что уже реализовано

- Тёмный нативный интерфейс с панелью поиска, встроенным браузером, навигацией, сменой зеркала и кнопкой отправки.
- Выбор озвучки, сезона и серии в отдельных меню поверх сайта; элементы синхронизируются с кликами на оригинальной странице.
- Чтение выбранного видео по разметке страницы / через одноимённый `get_cdn_series` API HDrezka, выбор MP4-качества, чекбоксы для субтитров SRT/VTT.
- Передача по HTTPS на `https://ps4-stream.onrender.com/api/launch`, генерация и показ PIN на телефоне; ввод PIN на PS4 — на постоянной главной странице.
- Хранение `API_KEY` в Android Keystore (AES-GCM), а не внутри JavaScript сайта.
- Добавление и удаление HTTPS-зеркал в настройках (начальные `rezka-tv.org`, `hdrezka-fly.net`, `hdrezka.ag`, `rezka.ag`, `rezka.fi`).
- Тестовая отправка открытого MP4 с MDN для независимой проверки Render / PS4.
- Нет `addJavascriptInterface`: JS читается только через `evaluateJavascript` на выбранных доверенных доменах.
- Только MP4; HLS, DASH и DRM не поддерживаются. Сайт и его API/вёрстка могут измениться.

## Вариант А. Получить APK через GitHub (без Android Studio)

1. Создай **отдельный** репозиторий GitHub `PS4Stream-Android` и загрузи **содержимое** этой папки в его корень.
2. Открой вкладку **Actions → Build Android APK → Run workflow**. Также сборка должна запускаться автоматически при push в `main`/`master`.
3. После успешной сборки открой соответствующий workflow run и скачай артефакт **PS4Stream-Android-debug**. Распакуй архив с файлом `app-debug.apk`.
4. Передай APK на телефон, разреши установку приложений из выбранного источника и установи.

В репозитории есть `.github/workflows/build-apk.yml`. Используется JDK 17, Android SDK 35, Gradle 8.13 и Android Gradle Plugin 8.13.2. Сборка на GitHub **ещё не запускалась**. Если упадёт, пришли ошибку workflow — исправим.

## Вариант Б. Собрать в Android Studio

1. Открой папку проекта в актуальной **Android Studio**, установи Android SDK Platform 35 и JDK 17.
2. Дождись Gradle Sync. Если предложено восстановить Gradle Wrapper — используй Gradle 8.13 (в репозитории есть `gradle/wrapper/gradle-wrapper.properties`, но нет бинарного `gradle-wrapper.jar`). При наличии локального Gradle 8.13 можно выполнить `gradle wrapper --gradle-version 8.13`.
3. Выбери **Build → Build APK(s)**. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск

1. Нажми шестерёнку и введи **API_KEY** из Environment настроек существующего сервиса Render. Сохранить.
2. Нажми **«Отправить тестовый ролик (MDN)»**. В приложении появятся 4 цифры. На PS4 или телефоне открой `https://ps4-stream.onrender.com/` и введи их. Код действует десять минут, используется один раз.
3. Открой нужный фильм в WebView. Выбери озвучку, сезон и серию на странице **или** нажми `Озвучка / серии` и выбери их из нативных меню.
4. Нажми **«Отправить на PS4»**, отметь качество и субтитры, затем отправь.
5. Введи PIN в браузере PS4. Видео воспроизводится по правилам текущего Render-сервера.

## Ограничения v0.1

- Каталог фильмов пока отображается самим сайтом во встроенном браузере. Красивые меню выбора потоков — нативные. Полностью нативный каталог с постерами — следующий этап.
- Быстрый поиск основан на распространённом URL поискового движка сайта; на некоторых зеркалах он может не сработать. Тогда воспользуйся поиском внутри самого сайта.
- Адаптер зависит от текущего формата `get_cdn_series` и селекторов переводов/серий. Некоторые страницы могут отдавать другие API или защищённые форматы, тогда выбор видео не сработает до адаптации.
- При смене перевода/эпизода на сайте подожди, пока он обновит плеер. Код получает ссылку с выбранной страницы в момент отправки.
- Субтитры скачиваются в Android-коде, без передачи Cookies. Если CDN требует специальные условия, приложение отправит фильм с предупреждением о неуспешной загрузке субтитров.
- Установка Android-приложения **не меняет** существующих ограничений видеоссылок: если Render видит от CDN 404, переключение на Android вряд ли исправит это.
- Храни API_KEY в секрете, не публикуй его в открытом исходном коде или скриншотах. Он сохраняется локально в Keystore.

## Структура

- `app/src/main/java/com/ps4stream/mobile/MainActivity.kt` — нативный интерфейс, встроенный браузер, меню качества/субтитров.
- `.../RenderClient.kt` — HTTPS-соединение с Render, PIN, загрузка субтитров.
- `.../SecureKeyStore.kt` — шифрование API_KEY в Android Keystore.
- `.../AppConfig.kt` — фиксированный Render URL и зеркала.
- `app/src/main/assets/rezka_adapter.js` — JS-адаптер к HTML/API сайта (работает в контексте WebView).
- `.github/workflows/build-apk.yml` — облачная сборка debug APK.
- `tests/test_adapter.js` — Node.js проверки парсера без сети.

### Тест парсера на ПК

```bash
node tests/test_adapter.js
```

Используй приложение только с контентом, на доступ и воспроизведение которого у тебя есть необходимые права. Не обходи DRM и ограничения доступа.
